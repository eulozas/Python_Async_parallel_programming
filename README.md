# Async_python_tasks

Проект содержит решения заданий по асинхронному и параллельному программированию на Python с применением мультипарадигмального подхода.  
Каждое задание оформлено как отдельный проект, где демонстрируются возможности асинхронного ввода/вывода, многопоточности и моделирования процессов.

## Задание 1. Экзамен

Смоделирована ситуация экзамена, где несколько экзаменаторов принимают студентов из общей очереди.  

### Логика работы

- Экзаменаторы работают в отдельных процессах.  
- Каждый студент отвечает на 3 вопроса, выбирая случайные слова в зависимости от пола (закон золотого сечения).  
- Экзаменатор оценивает ответы с учетом настроения и количества верных слов.  
- После 30 секунд работы экзаменатор может уйти на обед на случайное время (12–18 секунд).  
- Время экзамена зависит от длины имени экзаменатора.  

### Входные файлы

- `examiners.txt` — список экзаменаторов  
- `students.txt` — список студентов  
- `questions.txt` — банк вопросов  

### Вывод программы

Во время работы:

- Таблица студентов с текущим статусом: `Очередь`, `Сдал`, `Провалил`  
- Таблица экзаменаторов с информацией о текущем студенте, количестве принятых и заваленных студентов, времени работы  
- Количество студентов в очереди  
- Время с момента начала экзамена  

После завершения:

- Итоговая таблица студентов и экзаменаторов  
- Время экзамена  
- Лучшие студенты, лучшие экзаменаторы  
- Студенты, которые будут отчислены  
- Лучшие вопросы  
- Вывод о том, удался ли экзамен  


## Задание 2. Скачивание изображений

Реализован асинхронный загрузчик изображений.  

### Логика работы

- Пользователь вводит путь для сохранения файлов.  
- Пользователь вводит ссылки на изображения до пустой строки.  
- Программа асинхронно загружает изображения, не блокируя ввод новых ссылок.  
- Ошибки не прерывают выполнение, сохраняется состояние загрузок.  

### Вывод программы

- Сводка со статусами загрузок (`Успех` или `Ошибка`) в таблице  

## Технологии

- Python 3.10+  
- Модули `asyncio`, `multiprocessing` 
- Асинхронное/параллельное программирование  
- Мультипарадигмальный подход
